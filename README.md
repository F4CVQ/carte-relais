# Carte Relais

Application Android de **F4CVQ** : la carte des relais radioamateurs autour de vous.

- 1 700 relais et balises (France, Belgique, Italie du Nord) : FM, DMR, D-STAR, C4FM, SvxLink, EchoLink…
- Relais proches avec fréquences, shift, CTCSS, distance et azimut
- Prévision de liaison d'après le relief (profil de terrain, zone de Fresnel)
- Mode trajet, carnet d'écoute et couverture réelle, favoris, filtres par mode
- Correction et ajout de relais, recherche de lieu, widget, carte hors ligne

## Installation

1. Téléchargez **CarteRelais-vX.Y.Z.apk** dans la [dernière version](../../releases/latest) depuis votre téléphone.
2. Ouvrez le fichier et autorisez l'installation (Android 6 ou plus récent).
3. Les nouvelles versions sont ensuite signalées par l'application elle-même.

Gratuite, sans compte ni publicité.
